Homepage¶

Important

You are viewing the esm-dev documentation written by Yuan Sun, sharing code and methods for Earth system modeling in climate research. The source scripts are stored at esm-dev.

The authors have developed several new functionalities for the Community Terrestrial System Model (CTSM) under the supervision of Keith Oleson and Zhonghua Zheng. But these are not yet included in the official CTSM code repository. Model users are encouraged to taste these functionalities following the guidance in this documentation.

Related model source code for out-of-the-box application is open access at esm-dev_code with respective branch.
