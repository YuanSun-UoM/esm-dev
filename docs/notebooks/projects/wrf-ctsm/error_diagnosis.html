ERROR: ERROR: One or more of the CTSM cap output fields are NaN

note: This is the most common error from CTSM simulations, suggesting that CTSM does not get forcings on time. This could be caused by multiple factors, and I could not find a way to avoid it yet. In my understanding, CTSM is a heavy land surface model and uses hundreds of CPUs. But the number of CPUs for WRF simulations is constrained by grid spacing. Thus, it is challenging to run WRF-CTSM at ultra high spatial resolution, for example, 1 km.

solution:

  • Increase the time step to leave sufficient time for computing.

  • Increase threads and CPU cores.

  • Restart simulations based on wrfrst and ctsm restart files.
