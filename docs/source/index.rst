.. important::

   You are viewing the esm-dev documentation by `Yuan Sun <https://yuansun-uom.github.io>`_, sharing code and methods for Earth system modeling in climate research.

   Currently, the author development several new functionalities for the Community Terrestrial System Model (CTSM), but are not yet included in the official CTSM repository. Users are encouraged to use this documentation for experimental features.

   Related model source code is open access at `esm-dev_code <https://github.com/YuanSun-UoM/esm-dev_code>`_ with respective branch.
